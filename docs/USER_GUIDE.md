# User Guide

## Employer

1. Open [gaji-024.vercel.app](https://gaji-024.vercel.app).
2. Review or upload the worker roster.
3. Verify every address and amount.
4. Connect Freighter on Stellar Mainnet.
5. Review the batch total and sign the required actions.
6. Save transaction hashes as payroll receipts.

## Worker

1. Connect the wallet matching the roster address.
2. Review the batch and claim amount.
3. Sign `claim`.
4. Confirm the transaction in a Mainnet explorer.

Never share a secret key with an employer or the application.
