# Release Checklist

- [ ] Web build and tests pass.
- [ ] Contract tests pass.
- [ ] WASM release build succeeds.
- [ ] Public Vercel URL returns successfully.
- [ ] Mainnet Contract ID matches the manifest.
- [ ] Deployment manifest parses as JSON.
- [ ] Full batch transaction evidence is linked.
- [ ] Wallet secrets are absent.
- [ ] Worker-address verification is documented.
- [ ] README reflects current Mainnet status.
- [ ] User guide and operations runbook are available.
- [ ] Demo data is clearly distinguished from ledger evidence.
