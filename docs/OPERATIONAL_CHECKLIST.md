# Operational Checklist

## Roster

- [ ] Worker names and addresses are verified.
- [ ] Amounts use the correct decimal convention.
- [ ] Duplicate workers are removed.
- [ ] Batch total matches the source payroll file.

## Mainnet

- [ ] Wallet is on Stellar Mainnet.
- [ ] Contract ID matches the manifest.
- [ ] Every simulation succeeds before signing.
- [ ] Funding amount matches the batch total.
- [ ] Every hash is retained and reconciled.

## Completion

- [ ] Worker claims are confirmed.
- [ ] Batch status is re-read.
- [ ] Close transaction is successful.
- [ ] Payroll report links to explorer evidence.
